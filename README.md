🤖 ReadyBot

ReadyBot — компактный многофункциональный портативный гаджет на базе ESP32-C3 Super Mini с OLED-дисплеем и управлением одной кнопкой.

Проект создан для изучения микроконтроллеров, программирования Arduino, беспроводных технологий и разработки собственного портативного интерфейса.

✨ Возможности

🖥️ OLED Interface — собственный интерфейс с меню и анимациями.

📶 Wi-Fi — подключение к беспроводным сетям, отображение информации о подключении и IP-адреса.

🔵 Bluetooth LE — работа с Bluetooth Low Energy.

🌐 Web Server — локальный веб-сервер для взаимодействия с устройством.

🌤️ Weather — получение информации о погоде.

💾 Memory — сохранение данных и настроек во внутренней памяти.

🔋 Portable Design — питание от аккумулятора.

🌸 Startup Animation — собственная загрузочная анимация READYBOT.

🎯 Цели проекта

ReadyBot разрабатывается как компактная экспериментальная платформа для изучения возможностей ESP32-C3.

В дальнейшем планируется добавление новых функций, улучшение интерфейса, расширение беспроводных возможностей и оптимизация энергопотребления.
